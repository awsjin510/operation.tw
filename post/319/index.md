**重點整理**

- 大多數人每月付費訂閱 Claude 或 ChatGPT，卻只用到 5% 功能——通常只限於寫信、翻譯、修文案等基礎任務
- 《Claude 萬用手冊》是中文出版市場第一本完整涵蓋 Claude 全家桶的書籍，包含 Claude.ai、Desktop、Cowork、Code、Design、Computer Use、Skills、Connectors、Plugins 等九大模組
- 其中 Cowork 和 Skills 是最具實用價值的功能，能將日常工作流程時間從 90 分鐘縮短至數秒，同時無需重複撰寫 Prompt

## 為什麼 Claude 的付費訂閱功能大多被閒置？

大部分人訂閱 Claude 或 ChatGPT 後，日常使用方式往往只有三件事：寫信、翻譯、修改文案措辭，這代表每月 20 美金的訂閱費用中，至少 95% 的功能都沒被開發利用。有人在社群平台轉發過一句話：「你訂閱了 AI，但你只用它問簡單的問題。」這不是在責備使用者，而是指出一個現實——市面上缺乏系統性的指南，教人們如何完整使用這些工具的全部功能。

直到最近，市場上才出現第一本中文書籍專門解決這個問題。這本《Claude 萬用手冊》的上市時機不是巧合，而是與 Anthropic 公司最近的多波功能更新直接相關——從介面優化到生態整合，Claude 的版圖在過去幾個月快速擴展。

## 《Claude 萬用手冊》涵蓋哪些核心功能？

這本書將 Claude 的功能分為九個主要模組，分別是 Claude.ai（網頁版基礎介面）、Desktop（桌面應用程式）、Cowork（協作工具）、Code（代碼能力）、Design（設計功能）、Computer Use（電腦操作能力）、Skills（自訂技能）、Connectors（連接器）和 Plugins（外掛）。這套「全家桶」的概念可以進一步簡化為三個層級：介面層（如何存取 Claude）、能力層（Claude 能做什麼）和生態層（如何與其他工具整合）。

這是中文書市場首次有完整的書籍從頭到尾逐一介紹這些模組，不是片斷的教學文章或零散的網路貼文，而是系統化的知識框架。

## Cowork 如何讓每周工作時間大幅縮短？

Cowork 是 Claude 的協作功能，設計目的是讓多人共同與 AI 互動，但其實它最強大的應用是在個人工作流程優化——書中提到的實際案例是週報撰寫，原本需要 90 分鐘的任務，透過 Cowork 可以縮短到只需輸入一句話，就能完整生成。

這之所以可能，是因為 Cowork 允許使用者建立持續的上下文、記住工作模式和個人偏好。用戶不需要每次都從零開始重複解釋需求，AI 能夠理解你的工作風格、慣用的格式和品質標準。這不只是加快速度，而是根本上改變了人與 AI 協作的方式。

## Skills 功能為什麼讓你不用再寫 Prompt？

Skills 是這本書中最值得深入學習的章節，因為它代表了 AI 工具使用的一個範式轉移——從「每次都寫新 Prompt」轉變為「重複使用預設技能」。Skills 允許使用者將常用的複雜 Prompt 保存成可重複呼叫的技能包，就像在 Claude 內部建立自己的命令庫。

但這裡有一個更深層的技術問題：外部安裝的 SKILL.md 檔案本質上就是 Prompt injection 的載體。Prompt injection 是指透過巧妙的輸入，讓 AI 系統偏離原本的指示。當你從外部來源載入 Skills 時，實際上是在允許那個來源重新定義 Claude 對你的行為方式。這在提高效率的同時，也帶來了安全性考慮，是使用者必須理解的風險與收益的權衡。

## Claude 的三層功能架構對使用者有什麼實際意義？

將 Claude 功能分為介面層、能力層和生態層，幫助使用者理解自己應該在哪一層級進行優化。介面層決定你用什麼方式接觸 Claude（網頁、桌面應用還是其他方式），能力層決定 Claude 能為你做什麼（代碼、設計、電腦操作等），生態層決定 Claude 如何與你的其他工作工具整合（連接器和外掛）。

大多數人只停留在介面層的最基本操作，從未向下探索能力層和生態層。書中的整個論述框架就是在打破這種限制，逐步引導讀者認識 Claude 可以做什麼，以及如何將它嵌入到自己的日常工作流程中。

## 現在就能嘗試的具體行動是什麼？

本集 Podcast 最後給出一個「今晚下班回家就可以做」的具體行動建議：不是急著購買書籍或升級訂閱方案，而是打開 Claude，認真看一次自己過去一周最常進行的三項重複工作，思考哪一項最適合用 Skills 或 Cowork 來優化。

選定一項後，嘗試用自然語言描述你的完整需求——不要想著要寫「完美的 Prompt」，就是講清楚你平常怎麼做這件事。讓 Claude 幫你生成一個標準化的流程，保存它。下一次做同樣的事時，看看是否真的省了時間。這個小實驗會讓你親身體驗為什麼人們說他們只用了 5% 的功能——以及為什麼學會用剩下的 95% 能讓 AI 訂閱費物超所值。

## 常見問題

### Claude 付費訂閱每月要多少錢，包含哪些功能？

Claude 付費訂閱每月 20 美金，開放的功能包括 Claude.ai 網頁版、Desktop 桌面應用、Cowork 協作工具、Code 代碼能力、Design 設計功能、Computer Use 電腦操作、Skills 自訂技能、Connectors 連接器和 Plugins 外掛等模組。

### 什麼是 Claude 的 Skills 功能，它如何節省時間？

Skills 是一種保存和重複使用常見 Prompt 的功能，讓使用者無需每次都從零開始撰寫複雜指令。透過預先定義工作流程和偏好設定，使用者可以用簡短的一句話觸發完整的工作流程，大幅減少重複勞動。

### 《Claude 萬用手冊》這本書適合什麼樣的讀者？

這本書適合已經訂閱 Claude 但感覺沒有充分利用功能的使用者，或者想系統性學習 Claude 全部模組的使用者。它是中文市場首本完整介紹 Claude 全家桶的書籍，特別適合希望將 AI 工具深度整合到工作流程的專業人士。
